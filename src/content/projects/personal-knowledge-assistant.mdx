## Problem

Traditional chatbots lack knowledge of private documents and often generate responses without context. Users need an intelligent assistant capable of understanding uploaded PDFs and answering questions accurately based only on the document's content.

---

## Solution

Built a full-stack **Retrieval-Augmented Generation (RAG)** application that allows users to upload PDF documents and interact with them through a conversational AI interface.

The system extracts text from uploaded documents, converts it into vector embeddings, stores it in **ChromaDB**, retrieves the most relevant information for each query using semantic search, and generates grounded responses through a Large Language Model.

---

## Architecture

```text
User Uploads PDF
        ↓
Text Extraction
        ↓
Intelligent Chunking
        ↓
Generate Embeddings
        ↓
Store in ChromaDB
        ↓
User Question
        ↓
Semantic Retrieval
        ↓
LLM Generation
        ↓
Grounded Answer
```

## Key Features

- 📄 Upload and process PDF documents
- ✂️ Intelligent text chunking for efficient retrieval
- 🧠 Semantic embeddings using OpenAI Embeddings
- 🔍 Context-aware semantic search with ChromaDB
- 🤖 AI-powered question answering using OpenRouter LLMs
- 💬 Interactive chat interface built with Next.js
- 🗂 Session-based document memory
